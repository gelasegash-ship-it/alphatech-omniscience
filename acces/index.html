1. Ce que le site peut réellement voir

La vérité d'abord. Ton site est hébergé sur GitHub Pages, un hébergeur statique. Il ne produit aucun journal de connexion : pas d'adresse IP, pas de pays, pas de navigateur, pas d'heure de visite. Aucun outil au monde ne peut analyser des logs qui n'existent pas. Les chiffres ci-dessus ne mesurent pas les visiteurs du site : ils mesurent les clones du dépôt, ce qui inclut tes propres scripts et mes propres synchronisations.
Ce qu'il faut pour de vrais logs
  • Placer Cloudflare devant le domaine : journal des requêtes, IP, pays, blocage automatique des scanners, gratuit.
  • Ou déplacer le site sur un VPS (nginx) : logs complets, analyse fine, alertes.
  • En attendant, chaque page peut compter ses visites sans serveur, mais jamais identifier qui passe.

2. Double authentification TOTP — active-la maintenant

Génère ta clé, entre-la dans Google Authenticator ou Authy, puis valide un premier code. Le verrou protège l'accès à cette interface sur ton appareil.

Entre cette clé dans ton application d'authentification (saisie manuelle). Puis colle le code à 6 chiffres ci-dessous.
Double authentification active. Vérifiée le —.
Pour désactiver : saisir « JE CONFIRME » dans le champ code, ou fournir un code valide. Aucune désactivation silencieuse.
Ce que ce verrou ne fait pas. Il s'exécute dans le navigateur : il empêche quelqu'un qui prend ton téléphone d'ouvrir cette interface, il n'authentifie pas un serveur. La protection de compte réelle se configure chez chaque fournisseur, et ce n'est pas moi qui peux la cocher à ta place.
À activer chez chaque fournisseur, aujourd'hui
  • GitHub : Settings → Password and authentication → Two-factor authentication → application d'authentification + codes de secours à imprimer.
  • Meta (Facebook + Instagram) : Sécurité → Authentification à deux facteurs → application → codes de récupération.
  • Google : Sécurité → Validation en deux étapes → application + clés de secours.
  • WhatsApp : Vérification en deux étapes avec PIN à six chiffres.
  • Banque et MoMo : PIN jamais dicté, jamais photographié.
