Se brancher en une commande

Terminal, serveur, script de supervision :

curl -s https://gelasegash-ship-it.github.io/alphatech-omniscience/flux/feed.json | jq '.couverture'

Dans une page web ou une application :

fetch('https://gelasegash-ship-it.github.io/alphatech-omniscience/flux/feed.json')
  .then(r => r.json())
  .then(f => console.log(f.couverture.btc_sous_surveillance, 'BTC'));

Badge vivant sur n'importe quel site, sans écrire de code :

<script src="https://gelasegash-ship-it.github.io/alphatech-omniscience/embed/gardien.js" data-pos="br"></script>

Import dans un SIEM (Splunk, Wazuh, Elastic, Sentinel) :

sigma convert -t splunk regles_avancees.yml
sigma convert -t wazuh regles_avancees.yml

Ce que contient le flux, exactement

Les groupes les plus actifs avec leurs sites de fuite et leurs outils, les quatorze outils convertis en signatures, les portefeuilles sanctionnés encore approvisionnés, et une empreinte SHA-256 du flux lui-même. Si une seule valeur change sans que l'empreinte suive, le fichier a été altéré.

Le flux est statique, servi par un réseau de diffusion mondial : pas de clé d'API, pas de limite de requêtes, pas de serveur à faire tomber. Une entreprise peut le consommer toutes les heures sans rien nous demander. C'est volontaire : une défense qui dépend d'un serveur vivant s'arrête quand le serveur s'arrête.
